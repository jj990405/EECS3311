# Stage 2 녹화 가이드

최신 상세 대본은 [filming-script.ko.md](filming-script.ko.md), 인쇄용은 [filming-guide.pdf](filming-guide.pdf)입니다. GUI 일정 관리, 공부와 AI, CLI 및 최종 초기화의 세 영상으로 나누어 모든 F01–F15와 N01–N06를 시연합니다. 영상 개수와 길이는 과제의 고정 요구가 아니라 촬영을 위한 권장안입니다. 영어 음성 또는 읽을 수 있는 영어 자막으로 기능 ID, 입력, 결과와 AI 역할을 설명하세요. 얼굴 촬영은 명시 요건이 아닙니다.

실제 영상 URL과 시작 시간은 [demonstration-index.json](demonstration-index.json)에 입력합니다. 계획 구간 번호는 실제 타임스탬프가 아닙니다. 최종 보고서에는 접근 가능한 영상 링크와 실제 기능별 시작 시간이 필요합니다.
