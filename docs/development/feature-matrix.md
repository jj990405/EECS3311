# Feature inventory and implementation trace

Audit date: 14 November 2026. Source paths below are relative to `src/main/java/eecs3311/studyagent/`. D = deterministic, A = AI, H = hybrid. Each F ID is retained from the Stage 1 design report. Changed presentation/class boundaries are recorded in [patterns-and-changes](patterns-and-changes.md).

`MainWindow` and `CommandLineInterface` invoke the shared `AgentController` facade. The store persists approved entity changes; `StudyArtifacts` persists generated study items and scores; `InteractionHistory` persists agent interactions. No model has direct filesystem access.
